# Treasury content inventory

The canonical editable catalog is `catalog.json`; `GeneratedTreasury.kt` is generated by `python3 tools/treasury/treasury.py generate`. No app network request is needed. The source manifest pins the exact Holy See document; `sources/compendium.json` preserves 103 extracted paragraphs and their integrity hash. `.cache/` holds ignored HTTP cache files only.

The collection contains 61 distinct prayers, 28 with aligned Latin, and 78 explained expressions. Each explanation includes an origin, a biblical reference, Catechism paragraphs and a practical application. Source notes distinguish direct imports, common Brazilian formulas, editorial translations and original prayers. This is a devotional reference, not a substitute for the approved books of the liturgy.

## Editorial rules

- Preserve the app's existing Portuguese fixed prayers and full responsive Loreto litany exactly; tests detect drift.
- Align meanings, not equal character counts. Literal Latin glosses may differ from the inherited Portuguese; explain significant differences.
- Identify original texts and editorial translations. Do not ascribe original prose to a saint or call a paraphrase a quotation.
- Keep both source evidence and publication separate. Do not silently fix the snapshot to match an edited prayer.
- Give biblical references with enough context to distinguish a direct source from a theological association. Catechism references support the explanation, not a claim that the Catechism contains the prayer verbatim.
- No devotional promise of guaranteed healing, safety, wealth or a specific response. Intercession does not replace Christ's unique mediation or necessary practical care.
